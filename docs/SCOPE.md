# 研究范围文档：FADE — Factor Alpha Decay Estimation

> 版本 v0.1 | 最后更新：2026-05

## 一、研究动机

### 1.1 领域现状

近期 AI 驱动的因子挖掘领域（2024–2026）涌现大量工作：

| 系统 | 时间 | 方法 | 应对 alpha decay 的策略 |
|------|------|------|------------------------|
| AlphaGen / Alpha2 | 2022–2024 | RL + MCTS | 持续搜索新因子 |
| AlphaAgent | 2025.02 | 多 Agent LLM | 正则化探索 + 假设对齐 |
| FactorMiner | 2026.02 | LLM + 经验记忆 | 累积"成功结构"知识 |
| QuantaAlpha | 2026.02 | 进化 LLM | 自演化轨迹 |
| Alpha-R1 | 2025.12 | GRPO 微调 LLM | 推理对齐市场 reward |

**所有工作都在解决同一个问题**：如何更快/更好地"生产"新因子。

**没有任何工作处理另一面问题**：给定一个具体因子，预测其衰减速度。

### 1.2 与已有工作的关系

| 论文 | 做了什么 | 没做什么（即本研究的空白） |
|------|---------|-------------------------|
| Di Mascio et al. (2016) | 测量机构交易的平均 alpha 衰减约 12 个月 | 未做单因子级的预测 |
| Harvey et al. "Factor Zoo" | 65% 的异象样本外失效 | 未建模"哪些因子会失效" |
| Not All Factors Crowd Equally (arXiv:2512.11913, 已被撤回) | 双曲衰减理论 α(t)=K/(1+λt) | 实证不足；未做前瞻性预测 |
| Timing the Factor Zoo | 因子轮动择时 | 是择时，不是衰减预测 |

**本研究的独特定位**：在因子级别，做**前瞻性**的衰减预测，并以生存分析框架处理右截断。

## 二、研究问题

### 2.1 主问题（Primary）

给定一个公式化因子 `f` 在时刻 `t₀` 被发现：
- 输入：因子表达式 + 前 K 个月的 IC 时序 + 发现时刻的市场环境
- 输出：因子的 IC 半衰期 `H`，定义为首次出现"连续 3 个月 rolling IC < 0.5 × IC₀"的月数

### 2.2 子问题（Secondary）

- **S1**：因子结构特征对衰减速度的预测力有多大？（是否能在不依赖回测的情况下预测？）
- **S2**：早期 IC 动态需要观测多久才能产生有用的预测？（K=3 vs 6 vs 12）
- **S3**：哪类因子（动量/反转/价值/质量）的衰减最难预测？
- **S4**：基于衰减预测的主动因子替换策略，能否在样本外提升组合 IC？

## 三、数据方案

### 3.1 市场范围

- **主市场**：CSI 500（A 股，2010–2024）
- **二级验证**：CSI 1000（容量更小、衰减更快，可作为 stress test）

### 3.2 因子来源

```
Source 1: Qlib Alpha158        →  158 个工业级因子
Source 2: 系统性合成因子        →  从算子库枚举生成 ~5,000 个候选 → 筛选 ~800-1,500 个有效因子
Source 3: 学术异象因子（可选）  →  从 CSMAR 复现 ~50 个文献因子

合计预期：800–2,000 个因子
```

### 3.3 算子库（用于合成因子）

```
时序算子 (TS):    ts_mean, ts_std, ts_max, ts_min, ts_rank, ts_corr, ts_cov, delta
截面算子 (CS):    rank, zscore, scale
算术算子:         add, sub, mul, div, log, abs, sign
逻辑算子:         gt, lt, where
```

控制：表达式树深度 ≤ 4，回溯窗口 ∈ {5, 10, 20, 60} 天。

### 3.4 IC 时序回测

- 频率：月度 IC（基于日度信号的截面 Spearman 相关）
- 窗口：因子发现后追踪 60 个月，或至 2024-12 截止（whichever 更早）
- 工具：Qlib backtest engine

### 3.5 标签定义

```python
# 主标签（L1）：连续衰减半衰期
def half_life_label(ic_series, ic_0_window=6, threshold=0.5, persist=3):
    """
    ic_series: 月度 IC 时序
    ic_0_window: 用前 N 月计算初始 IC
    threshold: 衰减阈值（IC 降至初始值的多少倍视为衰减）
    persist: 需连续 N 个月低于阈值才算确认衰减
    返回：半衰期月数（若未衰减则为右截断，event=0）
    """

# 二级标签（L2）：N 月内是否衰减（分类）
# 三级标签（L3）：IC 时序的线性回归斜率（连续）
```

**右截断处理**：测试集结束时仍有效的因子，event=0，duration=观测窗口长度。这是用 Cox 模型的核心动机。

## 四、特征工程

### 4.1 组 A：因子结构特征（静态，无需回测）

| 特征 | 描述 |
|------|------|
| `tree_depth` | 表达式树深度 |
| `node_count` | 节点总数 |
| `ts_op_ratio` | 时序算子比例 |
| `cs_op_ratio` | 截面算子比例 |
| `max_lookback` | 最长回溯窗口 |
| `op_diversity` | 算子种类数 / 节点数 |
| `factor_type` | 启发式分类：动量/反转/波动率/量价/价值 |
| `raw_data_types` | 使用的字段集合 (close/volume/high/low...) |

### 4.2 组 B：早期 IC 动态特征（需要前 K 个月）

| 特征 | K=3 | K=6 | K=12 |
|------|-----|-----|------|
| `ic_mean_K` | ✓ | ✓ | ✓ |
| `ic_std_K` | ✓ | ✓ | ✓ |
| `icir_K` | | ✓ | ✓ |
| `ic_autocorr_K` | | ✓ | ✓ |
| `ic_trend_K` | | ✓ | ✓ |
| `ic_drawdown_K` | | ✓ | ✓ |

K 是超参，做敏感性分析。

### 4.3 组 C：发现时刻的市场环境

| 特征 | 描述 |
|------|------|
| `market_vol_60d` | 市场指数 60 日实现波动率 |
| `market_regime` | 牛/熊/震荡（HMM 三状态分类） |
| `factor_lib_size` | 当时已知因子数（拥挤度代理） |
| `novelty_score` | `1 - max(corr(f, f_i))` 与已有因子库的差异度 |
| `same_type_recent_decay` | 同类型因子近期平均 IC 趋势 |

## 五、模型设计

### 5.1 主模型：Cox 比例风险模型

```
风险函数：h(t|x) = h₀(t) · exp(βᵀx)

  - h₀(t)：基准风险函数（非参数估计）
  - β：特征系数向量（系数符号/显著性可解释）
  - x：拼接的 (A, B, C) 三组特征
```

**为什么用生存分析而非直接回归**：
1. 自然处理右截断
2. 输出生存曲线 S(t)，比点预测更丰富
3. 风险比 (HR) 是天然的特征重要性度量

### 5.2 对比模型

| 模型 | 类型 | 用途 |
|------|------|------|
| B1: 全局均值 | 朴素基线 | 下界 |
| B2: 按因子类型分组均值 | 简单基线 | 验证类型信息的价值 |
| B3: 双曲衰减拟合 | 理论模型 | 复现 arXiv:2512.11913 框架 |
| B4: XGBoost 回归 | ML 基线 | 不用生存分析的 ML 对照 |
| B5: LSTM | 序列模型 | 直接处理 IC 时序 |
| **M1: Cox-PH** | **主模型** | 本文方法 |
| M2: DeepSurv | 神经网络生存模型 | 增强版主模型 |

## 六、评估指标

```
点预测精度：
  - MAE (mean absolute error of half-life)
  - RMSE

排序精度：
  - Spearman ρ（预测 vs 实际半衰期排序）

生存分析专用：
  - C-index（一致性指数，~AUC）
  - Integrated Brier Score

下游应用：
  - 因子组合月度 IC 提升（基于预测主动替换 vs 随机替换）
```

## 八、Ablation 与分析

### 8.1 必做 Ablation

1. **特征组贡献**：A only / B only / C only / A+B / A+C / B+C / A+B+C
2. **观测窗口 K**：K ∈ {3, 6, 12} 月
3. **训练集规模**：50% / 70% / 100%
4. **因子类型分组**：分别在动量/反转/价值/质量子集上的预测精度

### 8.2 案例研究

挑选 5–10 个有代表性的因子（如 momentum_20d、value_book_to_price、reversal_5d），画出：
- 实际 IC 衰减曲线
- 模型预测的生存曲线
- 双曲衰减理论模型的拟合曲线

直观展示模型的预测质量。

## 十、风险与应对

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 因子样本量不够（<500） | 中 | 高 | 用 L3 (IC 斜率) + 滚动窗口扩充样本 |
| 合成因子质量低，IC 都接近 0 | 中 | 中 | 引入 Qlib Alpha158 + 学术因子作为锚点 |
| Cox 比例风险假设不成立 | 中 | 中 | 改用 AFT 模型或 DeepSurv |
| 与撤回论文 arXiv:2512.11913 重叠过大 | 低 | 高 | 我们做前瞻性预测；他们做事后曲线拟合，定位不同 |
| 衰减标签定义敏感性强 | 高 | 中 | 提供三种标签 L1/L2/L3 的对比实验 |

## 十一、范围之外（明确不做）

- **不做**因果推断（causal factor discovery）—— 单独的研究方向
- **不做**多市场迁移（A 股训练，美股测试）—— 留作 future work
- **不做**实时拥挤度估计的市场微观结构建模 —— 用代理指标
- **不做**新因子生成 —— 我们只预测已有因子的衰减
- **不做**LLM 解释生成 —— 保持模型简洁
